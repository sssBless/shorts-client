# Shorts Editor

React-клиент для вашего сервера нарезки Shorts.

## Запуск локально

Из корня workspace:

```bash
pnpm install
pnpm --filter @workspace/shorts-editor run dev
```

Открывайте preview из Replit либо адрес, который напечатает Vite.

## Подключение backend

По умолчанию клиент отправляет запросы на:

```text
/api/v1/video/analyze
/api/v1/video/approve
```

Если backend запущен локально на Windows, откройте в правом верхнем углу настройки и укажите:

```text
http://localhost:3000/api
```

Тогда клиент будет вызывать:

```text
http://localhost:3000/api/v1/video/analyze
http://localhost:3000/api/v1/video/approve
```

Backend должен разрешать запросы из браузера через CORS.

## Рабочий сценарий

1. Нажмите `Загрузить видео`.
2. После загрузки появится первый фрагмент на 15 секунд.
3. Выберите фрагмент в списке.
4. Передвигайте зеленую и оранжевую ручки на timeline.
5. Для точного значения используйте поля `Start` и `End`.
6. Во время воспроизведения выбранный фрагмент останавливается на своем `End`.
7. Нажмите `Analyze speech`.
8. Исправьте слова в правой панели.
9. Нажмите `Approve & render`.

Клиент отправляет серверу массив `words` с `id`, `word`, `start` и `end`, поэтому ASS вручную редактировать не нужно.
